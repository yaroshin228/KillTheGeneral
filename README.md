# Убей генерала (Kill the General)

Простая консольная игра на C++ с элементом случайности.

## Правила
- Генерал выбирает одну из двух кружек (1 или 2)
- Игрок должен отравить правильную кружку
- При совпадении - победа, иначе - поражение

## Сборка
```bash
g++ -o kill-the-general kill-the-general.cpp
./kill-the-general
```
